# Manuscript figure code

R code to reproduce the figures reported in an upcoming manuscript (single-cell and bulk RNA-seq analyses).

## Contents
- `code/` — R Markdown scripts that generate the manuscript figures.

## Data availability
The processed single-cell data can be explored interactively via a web application:

**https://shiny-public.fgcz.uzh.ch/app/rmb_ethz_forskolin_muscle_scRNA**

Raw sequencing data are restricted (human samples) and available from the corresponding
author on reasonable request.

## Software
R, with a single-cell analysis toolchain (Seurat / ShinyCell2 and related packages;
see the individual scripts for their dependencies).
